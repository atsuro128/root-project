レビューセッション開始時の状態確認と対象提案を実行してください。

## 実行手順

### 1. 前回レビューの引き継ぎ確認

`/root-project/dev-journal/review-log.md` を Read する。

- ファイルが存在する場合: 前回の「未確認」「疑問・メモ」を把握する
- ファイルが存在しない場合: 「初回レビュー」として続行する

### 2. 進捗確認

`/root-project/dev-journal/progress-management/progress.md` を Read し、現在のフェーズを把握する。

### 3. レビュー対象の提案

以下の優先順位で提案する:

1. 前回レビューの未確認範囲がある場合: 続きから
2. 前回レビューの疑問・メモがある場合: 疑問の解消から
3. どちらもない場合: 直近で完了した Step の成果物を提案

提案時は「レビュー対象候補: ～」と明示し、ユーザーの合意を得てから開始すること。

### 4. セッション種別の通知

以下をユーザーに伝える:

> このセッションはレビューセッションです。終了時は `/human-review-log` でログを記録します。
