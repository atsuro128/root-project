自動読み込みコンテキストを「実際に作業の助けになるか」の観点で査定してください。

## 査定対象

1. **CLAUDE.md**（プロジェクトルート）
2. **`.claude/rules/` 配下の全ファイル**
3. **セッション開始時に読むファイル**（workflow.md のセッション管理で指定されているもの）

## 手順

1. 査定対象のファイルを全て読み込む
2. 各ファイルをセクション単位で以下の観点で評価する
3. 評価結果をユーザーに報告する

## 評価観点

各セクションについて以下を判定する:

| 評価 | 基準 |
|------|------|
| **有用** | 作業中の判断・行動に直接影響する |
| **微妙** | たまに参照するが、必要時に読めば足りる / 他で担保済み |
| **不要** | 作業判断に使わない / 完全に他と重複 |
| **不整合** | 現在の環境・運用と合っていない |

## 報告形式

ファイルごとにセクション単位の評価テーブルを出力し、最後に総合所見をまとめる:

```markdown
### [ファイル名]（自動読み込み / セッション開始時・XX行）

| セクション | 評価 | 理由 |
|---|---|---|
| ... | 有用 / 微妙 / 不要 / 不整合 | ... |

### 総合所見
- 最もコスト対効果が悪いファイル・セクション
- 削除・統合・移動の提案
- 推定削減トークン数
```
